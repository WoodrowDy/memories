# Infra

> **범위:** 코드를 밖에 내보내고 굴리는 모든 것. AWS·NCP 같은 클라우드,
> 컨테이너, CI/CD, 서버리스, 모니터링.
> 코드 안에서 끝나는 이야기는 `cs`나 `lang`으로.

## 작성 예정

- AWS Lambda — 실행 모델, 콜드 스타트, 동시성 상한
- SQS — 비동기 경계를 만드는 이유, 가시성 타임아웃과 DLQ
- AWS — IAM, API Gateway
- NCP
